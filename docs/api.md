# API

All endpoints are under `/api`. Auth is a JWT in the `Authorization: Bearer <token>` header. Times are ISO 8601 with timezone, returned in UTC.

Full schema is generated by FastAPI at `/api/docs`.

## Auth

| Method | Path | Access | Description |
|---|---|---|---|
| POST | `/auth/register` | public | Create account, role is always `user` |
| POST | `/auth/login` | public | Returns access token |
| GET | `/auth/me` | user | Current user |

## Rooms

| Method | Path | Access | Description |
|---|---|---|---|
| GET | `/rooms` | user | List active rooms, filter `?min_capacity=` |
| GET | `/rooms/{id}` | user | Room details |
| GET | `/rooms/{id}/bookings` | user | Active bookings in range `?from=&to=` |
| POST | `/rooms` | admin | Create room |
| PATCH | `/rooms/{id}` | admin | Update room |
| DELETE | `/rooms/{id}` | admin | Deactivate room (`is_active = false`) |

## Bookings

| Method | Path | Access | Description |
|---|---|---|---|
| POST | `/bookings` | user | Create booking |
| GET | `/bookings/me` | user | Own bookings, `?upcoming=true` |
| POST | `/bookings/{id}/cancel` | owner / admin | Cancel booking |

## Other

| Method | Path | Access | Description |
|---|---|---|---|
| GET | `/health` | public | App + db status |

## Examples

`POST /auth/login`

```json
{ "email": "jan@uni.pl", "password": "secret" }
```

```json
{ "access_token": "eyJ...", "token_type": "bearer" }
```

`POST /bookings`

```json
{
  "room_id": 3,
  "title": "Project meeting",
  "starts_at": "2026-11-05T10:00:00+01:00",
  "ends_at": "2026-11-05T11:30:00+01:00"
}
```

## Errors

All errors return `{ "detail": "..." }`.

| Code | When |
|---|---|
| 401 | Missing or invalid token |
| 403 | Not allowed, e.g. user calling an admin endpoint |
| 404 | Room / booking not found |
| 409 | Booking overlaps another one, email already taken |
| 422 | Validation error, e.g. `ends_at` before `starts_at` |
