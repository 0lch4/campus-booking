# Backend

FastAPI app. Config is read from env vars or `.env` (in `backend/` or repo root, see `.env.example`).

## Run locally

```
python -m venv .venv
.venv\Scripts\activate        # Linux / macOS: source .venv/bin/activate
pip install -e .
uvicorn app.main:app --reload
```

- API: http://localhost:8000/api
- Docs: http://localhost:8000/api/docs
- Health: http://localhost:8000/api/health, returns 503 if the db is unavailable

Start the db first (see the root README). When running `uvicorn` outside Docker, set `POSTGRES_HOST=localhost` in `.env`, because `db` only resolves inside the Docker network.

## Auth

All endpoints except `/api/health`, `/api/auth/register` and `/api/auth/login` need a token. Get it from `POST /api/auth/login` and send it as `Authorization: Bearer <token>`. In the docs use the **Authorize** button and paste only the token.

Room changes (`POST` / `PATCH` / `DELETE /api/rooms`) need the `admin` role, other users get 403. Registration always creates a `user`, admins come from the seed.

## Migrations

```
alembic upgrade head                        # apply all migrations
alembic revision --autogenerate -m "name"   # create a new migration from model changes
alembic downgrade -1                        # undo the last migration
```

Review autogenerated migrations before committing. On `downgrade`, Postgres enum types have to be dropped by hand.

## Seed data


## Docker

Run from the repo root, with the db started from `docker compose` (see the root README):

```
docker build -t campus-booking-backend backend
docker run --rm --network campus-booking_default --env-file .env -e POSTGRES_HOST=db campus-booking-backend alembic upgrade head
docker run --rm --network campus-booking_default --env-file .env -e POSTGRES_HOST=db -p 8000:8000 campus-booking-backend
```

The container doesn't run migrations on start, so run them after every schema change. The network name comes from the repo folder name.
